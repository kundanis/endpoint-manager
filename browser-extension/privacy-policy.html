Endpoint IQ Browser Guard – Privacy policy

Last updated: 24 November 2026

Endpoint IQ Browser Guard (formerly Endpoint IQ Mail Guard) is a browser extension for Google Chrome and Microsoft Edge. It is installed and set up by organizations that use Endpoint IQ, to stop personal or confidential data from being sent by email from Gmail, or shared with AI websites such as ChatGPT, Gemini or Claude, against the organization's policy. It does nothing unless the user's organization has set it up.

What the extension reads

On Gmail (mail.google.com) only, the extension reads:

  • the files a user attaches to an email, and
  • the subject and text of the email the user writes, and
  • the email addresses of its recipients, to tell whether it is going only to the organization's own domains.

On AI websites listed in the extension (for example chatgpt.com, gemini.google.com, claude.ai), and only when the organization has turned on AI prompt protection for the computer, the extension reads:

  • text the user pastes into the AI website,
  • the prompt the user is about to send, and
  • files the user uploads to the AI website.

It checks them on the user's own computer for the kinds of personal or confidential data the organization has chosen to protect, such as card numbers, PAN, Aadhaar, bank details or the organization's own keywords.

What the extension sends, and where

The extension sends data only to the user's organization's own Endpoint IQ server, which the organization runs and controls. It sends:

  • the user's Gmail address, to find out which policy applies to them; and
  • when it blocks something: the Gmail address, the file name (or "Message text"), and the kind of data found, for example "PAN";
  • on AI websites: the computer's Endpoint IQ identifier (set by the organization), to find out which policy applies; and, when it warns about, blocks or masks something, the AI website's address, the file name if it was a file, the kind of data found and a masked sample of it (for example "4111 •••• •••• 1111").

It never sends the content of emails, prompts or files, the recipients' addresses, or the personal data it found in readable form.

What the extension does not do

  • It does not sell, rent or share any data with anyone.
  • It does not send any data to the extension's publisher or to any third party.
  • It does not show advertising or track browsing.
  • It does not read or change any website other than Gmail and the AI websites listed in the extension.
  • It does not use data for any purpose other than applying the organization's email and AI policies.

Storage and retention

The extension itself stores no personal data. Block reports are kept on the organization's own Endpoint IQ server, under that organization's own retention rules.
